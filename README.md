# Visual references for the private library

These images were included as references for the Librarian Desk upload tool. They are not used as public website files.

| File | Best use in the website |
|---|---|
| dark-library-door.png | Outside-library background on the entry screen |
| enchanted-tree-library.png | Reading Alcove artwork or an alternate entry visual |
| gothic-garden-gate.png | Optional first screen before the library door, or a future private landing page |
| illustrated-book-spines.png | A visual reference for real, decorative book-cover styling |

After deployment, sign in to the private library, open Librarian Desk, and upload the first three through the visual-texture uploader. Use the book-spines image as a design reference or crop it into individual cover textures before uploading it to individual books.
